# 🌐 JS Solution: Business Website

A fast, single-page business website for **JS Solution**, a company offering everything from AI invitations and home products to smart home, kitchen appliances, web & app development and repair services.

> Screenshot: add `screenshot.png` here

## Features

- Modern hero section: "One Place for All Kinds of Solutions"
- Service cards for 6 business categories
- Scroll-reveal animations
- Contact / "Get in touch" section
- Fully responsive on mobile, tablet and desktop
- Zero dependencies: a single `index.html` that loads instantly

## Tech stack

HTML5 · CSS3 · Vanilla JavaScript

## Run locally

Open `index.html` in any browser. To publish it, drag the folder onto Netlify or Vercel.
